Join Axiom Labs.

We are an open, student-led group of peer researchers. If you want to write papers or ship tools with us, tell us what you would like to work on.

Where you could fit

Research collaborator

Take a problem from statement to preprint. Best if you are strong in maths, statistics or physics.

Software contributor

Improve Spectre, write tests, build demos, make tools easier to run.

Domain expert

Chemists, energy engineers and quants who can tell us when a model is wrong.

Advisor

Faculty and practitioners who can review work or open doors.

Problems we want help with

NMR for Spectre

Extend the inverse-problem approach from infrared to NMR spectra.

Spectroscopy, machine learning

Constrained GPs beyond volatility

Shape constraints such as monotonicity and convexity in the covariance of other surfaces.

Gaussian processes, numerics

Optimal transport kernels

Regression on distributions using transport distances.

Optimal transport, kernel theory

Open benchmarks for energy disaggregation

Shared datasets and evaluation rules so methods can be compared fairly.

Signal processing, data

How it starts

  1. Email us what you want to work on, with a link to something you have made.
  2. We reply with a short call and a small starter task.
  3. If it fits, you join a project and the author list is agreed up front.

Questions

Do I need to be a student?

No. Tell us where you are based and how much time you can commit.

Is it paid?

Axiom Labs is student-led and independent. Projects are currently unpaid research collaborations.

How is authorship decided?

By contribution, agreed at the start of a project and revisited if the scope changes.

What tools do you use?

Python and JavaScript, LaTeX for papers, and GitHub for code.
